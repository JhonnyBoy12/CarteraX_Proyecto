      Llamada manual

      Cómo conectar

      1. Instala y abre Phoenix Mobile en el teléfono Android.
      2. Acepta el permiso para realizar llamadas.
      3. Conecta el PC y el teléfono a la misma red Wi‑Fi.
      4. Escribe la IP que aparece en el teléfono y pulsa «Probar conexión».
      5. En Clientes, pulsa un número para llamar. Cada llamada queda registrada.
