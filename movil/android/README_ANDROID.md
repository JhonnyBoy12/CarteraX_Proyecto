# Compilar Phoenix Mobile

1. Instala Android Studio.
2. `File` → `Open` → selecciona la carpeta `android` de este ZIP.
3. Espera la sincronización de Gradle.
4. Conecta el teléfono por USB con Depuración USB o usa el método habitual de Android Studio.
5. Pulsa Run.

Para generar un APK instalable:

`Build` → `Build App Bundle(s) / APK(s)` → `Build APK(s)`

El APK normalmente quedará en:

`app/build/outputs/apk/debug/app-debug.apk`

Al abrir Phoenix Mobile en el teléfono, la pantalla mostrará la IP local que debes escribir en Phoenix Phone Test para Windows.
