      Llamada manual

      Cómo vincular

      1. Instala y abre Phoenix Mobile en el teléfono Android y deja todo en verde en «Para que no se corte».
      2. Conecta el computador y el teléfono a la misma red Wi‑Fi.
      3. Pulsa «Buscar teléfonos», elige el tuyo y escribe el código de 6 dígitos que muestra.
      4. Listo: ese teléfono sólo recibe llamadas de este computador, aunque en la oficina haya otros en la misma red.

      Si el teléfono cambia de IP, CarteraX lo vuelve a encontrar solo. ¿Sin teléfono a mano? Ejecuta npm run simulador-movil.
