      Cómo vincular

      1. Instala y abre Phoenix Mobile en el teléfono Android.
      2. Concede los permisos de llamadas, estado del teléfono y registro de llamadas. Los dos últimos permiten que la cola sepa cuándo terminó cada llamada.
      3. Conecta el computador y el teléfono a la misma red Wi‑Fi.
      4. Escribe la IP que aparece en el teléfono y pulsa «Probar conexión».

      ¿Sin teléfono a mano? Ejecuta npm run simulador-movil y usa la IP 127.0.0.1.
